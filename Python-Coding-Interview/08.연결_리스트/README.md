### 런너 기법
- **연결 리스트를 순회할 때 2개의 포인터를 동시에 사용하는 기법.**
- 한 포인터가 다른 포인터보다 앞서게 하여 병합 지점이나 중간 위치, 길이 등을 판별할 때 유용하게 사용
- 보통 빠른 포인터는 두 칸씩 건너뛰고, 느린 포인터는 한 칸씩 이동하게 한다.
    - 빠른 포인터가 끝에 도달하면 느린 포인터는 정확히 연결 리스트의 중간을 가리키게 된다.
    - 이후 값을 비교하거나 뒤집기를 시도하는 등 여러 방식으로 활용할 수 있어 연결 리스트 문제에서 자주 쓰인다!
