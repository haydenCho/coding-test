### 연결 리스트 관련 파이썬 메서드
- (리스트) pop(): 값을 반환
    - pop(인덱스): 인덱스에 해당하는 값을 반환
- divmod(a, b): 몫과 나머지로 구성된 튜플(a // b, a % b) 반환

### 런너 기법
- **연결 리스트를 순회할 때 2개의 포인터를 동시에 사용하는 기법.**
- 한 포인터가 다른 포인터보다 앞서게 하여 병합 지점이나 중간 위치, 길이 등을 판별할 때 유용하게 사용
- 보통 빠른 포인터는 두 칸씩 건너뛰고, 느린 포인터는 한 칸씩 이동하게 한다.
    - 빠른 포인터가 끝에 도달하면 느린 포인터는 정확히 연결 리스트의 중간을 가리키게 된다.
    - 이후 값을 비교하거나 뒤집기를 시도하는 등 여러 방식으로 활용할 수 있어 연결 리스트 문제에서 자주 쓰인다!

### 숫자형 리스트를 단일 값으로 병합
- a = [1, 2, 3, 4, 5]일 때, `int(''.join(str(e) for e in a))`와 같이 숫자 → 문자 → 숫자 변환을 하는 건 가독성이 떨어진다.
- `int(''.join(map(str, a)))`: map()을 사용하면 문자열 변환을 암시할 수 있어 비교적 가독성이 좋다.
- `functools.reduce(lambda x, y: 10 * x + y, a, 0)`: x에 10을 곱해서 자릿수를 올리고 y를 더하는 방식. 값이 누적되어 결과는 12345가 된다.
    - **functools**: 고계 함수(Higher-Order Function_함수를 다루는 함수)를 지원하는 함수형 언어 모듈
        - **reduce**: 두 인수의 함수를 누적 적용하는 메소드
